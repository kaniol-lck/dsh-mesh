# 工作日志约定（本地，不入库）

`.worklog/` 是本地工作日志。**明细永不提交**：`.worklog/` 整体被 `.gitignore` 忽略，只有本文件与 `WORKLOG.md` 作为约定/索引入库（已跟踪，之后修改照常提交）。

## 目录结构

| 路径 | 用途 |
|---|---|
| `README.md` | 本约定（唯一入口） |
| `WORKLOG.md` | 滚动日志，倒序，新条目加在**顶部** |
| `todo/<会话>.md` | 各会话的待办清单（`hub` / `waker` / `docs`） |
| `archive/YYYY-MM.md` | 月度归档，整月日志搬入 |
| `dispatch/` | 派活载荷（纯文本任务正文），可随时删 |

## 待办：`todo/<会话>.md`

每个文件首行固定，更新条目时同步改日期：

```
<!-- session: <名> · updated: YYYY-MM-DD -->
```

条目一行一条，字段顺序固定：

```
- [P0|P1|P2] <标题> —— <一句话说明>；验收：<可验证标准>；状态：未开始|进行中|已完成
```

规则：

- 每个执行会话**只写自己的** `.worklog/todo/<自己>.md`，协调会话不改别人的文件（只读、汇总）；
- 待办完成就改状态与验收结论，不要另起文件；过期的直接删或用 `archive/` 归档；
- 标题用一句话说清动作，说明写“为什么/影响面”，验收必须可被命令或肉眼逐条核对。

## 汇总：协调会话 → `..\ROADMAP.md`

- 协调会话把各 todo 的摘要汇总进仓外的 `..\ROADMAP.md`；
- ROADMAP 只放**阶段目标与取舍**，明细（验收、状态、负责人）留在本目录的 todo 文件；
- 执行会话不直接改 ROADMAP。

## 滚动日志：`WORKLOG.md`

任务完成 / 故障 / 发版时，在 `WORKLOG.md` **顶部**追加一行（倒序）：

```
YYYY-MM-DD HH:mm · <会话> · <动作> · <产物或 commit>
```

- 发版、部署那行必须注明「owner 确认」与确认时间；
- 没有确认记录的发版视为违规，事后补记也要写明是补记。

## 收尾检查

- `git status` 除 `.worklog/` 外必须干净；`.worklog/` 下只有 `README.md` / `WORKLOG.md` 曾被跟踪；
- 不要把 `todo/`、`dispatch/`、`archive/` 加进暂存区（不要用 `git add -A`）；
- 需要把日志带进交接包/镜像仓时，导出摘要到 `docs/`，不要整体拷贝本目录。
